# Bell Performance 13.11.0 — Discipline-Wide Scientific Validation

This release expands the locked 13.10.5 scientific-validation baseline across all seven canonical coaching disciplines.

## Seven clean controls

- Performance & Health
- Powerlifting
- Bodybuilding
- Hybrid Athlete
- Tactical Athlete
- Functional Fitness
- Endurance Athlete

Each control runs a 52-week journey at a 90% target-compliance condition with six phases: Foundation, Development I, Recovery & Assessment, Development II, Specific Capacity, and Consolidation.

## Acceptance standard

A discipline is not approved merely because the year completes. The review must confirm:

1. all 52 formal weeks exist;
2. no browser/runtime failures occur;
3. time budgets are respected;
4. the discipline's protected sessions remain present;
5. progression changes across phases;
6. recovery and assessment weeks reduce or redirect fatigue;
7. actual compliance is reported separately from prescription quality;
8. known-bad discipline-specific mutations are rejected without false alarms.

The included `discipline_validation_matrix.json` defines the guardrail families and catalogs every supported event type for the following event-validation track.
