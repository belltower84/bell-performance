# Bell Performance 12.2.11 — Weekly Plan List

## Dashboard change
- Replaced the compact day-card carousel with a clean vertical weekly list.
- Each row shows the weekday, date, and the actual major training prescription.
- Blended days display both sessions, such as **Upper Strength + Easy Engine**.
- Rest days display **Rest / Recovery**.
- The list scrolls vertically when needed and automatically brings today into view.
- Mobility and core remain inside the workout and do not clutter the weekly list.

## Scope
Frontend-only display refinement. Scheduling and programming logic are unchanged.
