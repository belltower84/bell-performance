# Bell Performance 13.0.1 — Powerlifting Loading Fix

- Restores visible squat, bench press, deadlift, and optional push-press max fields during First Flight onboarding.
- Requires the three competition-lift maxes when Powerlifting is selected.
- Automatically calculates the back-off exercise card from the prescribed top-set load.
- Automatically updates unfinished back-off sets when the athlete changes the top-set weight during the workout.
- Keeps max lifts editable in Athlete Settings.
