# Bell Performance 13.18.1 — Guided Workout Focus

- Replaces the dense set tracker with one current exercise and one current set.
- Prefills planned weight and reps; the athlete usually only taps Complete Set.
- Keeps result editing behind an optional Adjust Result control.
- Adds a compact exercise queue and clear Next Up prompt.
- Changes the session/rest timer into a small inline status bar that does not cover training content.
- Keeps detailed exercise guidance, substitutions, and feedback available without forcing interaction.
- Simplifies the end-of-session flow while preserving Bell Coach inputs and the validated coaching engine.
