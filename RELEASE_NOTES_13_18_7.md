# Bell Performance 13.18.7

## Exercise Header, Editable Set Grid & Load Feedback

- Sticky exercise title and exercise count during training.
- All sets remain visible on one exercise screen.
- Weight and reps are editable inline and prefilled when available.
- After all sets, athlete rates the suggested load: Too hard, Just right, or Too light.
- Load rating is stored on the exercise for later coaching use.
- Rest timer is compact and anchored below content without covering set rows.
