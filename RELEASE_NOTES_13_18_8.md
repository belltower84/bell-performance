## Compact Workout Execution UI

- Keeps the active exercise title pinned at the top.
- Shows Exercise X of Y and compact primary-muscle indicators.
- Presents all sets as a dense one-line list with editable weight and reps.
- Adds completed and skipped set states.

- Tapping Next Set without completing the current set records it as skipped.
- Adds explicit Skip Set behavior.
- Keeps exercise load feedback above the fixed next-exercise dock.
- Moves the rest timer into normal document flow so it cannot cover set rows.
