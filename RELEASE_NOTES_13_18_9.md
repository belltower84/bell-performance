# Bell Performance 13.18.9

## Dense Workout Log & Fixed Action Dock

- Converts each exercise into a compact, single-line set list.
- Keeps Exercise N of M, exercise title, and muscle groups pinned at the top.
- Keeps weight and reps prefilled and editable inline.
- Places load feedback directly below the completed exercise set list.
- Locks the next exercise preview to a compact bottom dock.
- Adds explicit Skip Set and Next actions at the bottom.
- Tapping Next on an incomplete set logs that set as skipped before advancing.
- Hides the legacy oversized workout timer/control card during guided execution.
- Keeps the rest timer compact and in page flow.
