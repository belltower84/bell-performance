# Bell Performance 13.19.2 — Workout State Clarity & Compact Navigation

- Replaces ambiguous status icons with explicit text states: Complete, Completed, and Skipped.
- Adds a clear secondary Skip action to each unfinished set.
- Clicking Completed or Skipped restores the set for correction.
- Restores visible Save & Exit and Discard controls in the fixed exercise header.
- Keeps Previous and Next exercise navigation available without automatically skipping unfinished sets.
- Tightens the set rows and bottom navigation dock.
- Preserves editable prefilled weight and reps.
