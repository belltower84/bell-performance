# Bell Performance 13.20.3

## Completion-Gated Exercise Feedback

- Keeps exercise load feedback hidden while any set is unfinished.
- Reveals and scrolls the feedback panel into view only after every set is completed or skipped.
- Temporarily replaces set controls with a clear rate-to-continue message.
- Selecting Too Hard, Just Right, or Too Light saves the rating and advances to the next exercise.
- Preserves Save & Exit, Discard, set editing, rest timer, and exercise navigation state.
