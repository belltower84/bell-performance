# Bell Performance 13.22.5 — Mission Location & Engine Selectors

## Restored Today’s Mission controls
- Strength sessions show a **Training at** selector inside Today’s Mission.
- Engine sessions show an **Engine mode** selector inside Today’s Mission.
- The selected setup is also summarized on each session choice card.

## Behavior
- Changing the strength location updates the active equipment inventory used for automatic substitutions.
- Changing the engine modality preserves the programmed training purpose, effort, and duration while changing the execution mode.
- Saved locations and the chosen active setup remain persistent.
