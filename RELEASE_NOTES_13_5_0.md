# Bell Performance 13.5.0 — Commercial Athlete Experience

## Purpose
13.5.0 begins the complete front-end modernization while preserving Bell 13.4 coaching intelligence, Journey planning, discipline libraries, workout generation, and coaching memory.

## Home dashboard
- New plain-language Home experience centered on today's training.
- Dominant Start Training action.
- Daily readiness prompt with Low, Ready, and Great choices.
- Simple session summary, duration, and reason for the workout.
- Seven-day week strip with completion states.
- Bell Coach direction, current Plan, and progress snapshots.
- Guided and Advanced display modes.

## Navigation
Primary athlete-facing navigation is now Home, Train, Plan, Progress, and More.

## UX foundation
- New commercial card, button, spacing, type, and mobile-navigation system.
- Larger touch targets and simpler information hierarchy.
- Existing advanced Bell features remain connected behind familiar language and secondary actions.

## Compatibility
No coaching data is reset. Existing Bell Core integration, athlete profiles, powerlifting loading, Journey state, settings, memories, history, and workout player remain intact.
