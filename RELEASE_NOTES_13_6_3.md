# Bell Performance 13.6.3 — Streamlined Settings

## Settings home
- Replaced the long, tab-heavy Settings page with a compact control-center home.
- Added an athlete summary showing current identity, objective, application mode, phase, and profile completion.
- Added six clear destinations: **Athlete Profile**, **Mission & Program**, **Training Setup**, **Recovery & Nutrition**, **Bell Behavior**, and **Help & Data**.

## Focused settings flow
- Each destination now opens its own focused page with the standard Bell back control and consistent section hierarchy.
- Combined recovery and nutrition into one logical health section while preserving the existing controls and saved data.
- The profile shortcut opens Athlete Profile directly; selecting Settings from navigation always returns to the Settings home.

## Bell Behavior
- Replaced the application-control dropdown with two large mode cards: **Workout Planner** and **Bell Coach**.
- Workout Planner continues to hide adaptive-coaching preferences.
- Bell Coach exposes coaching detail, check-in frequency, message style, and optional scripture frequency.

## Program and app controls
- Kept the current Journey overview prominent while collapsing manual block, Mission-goal, Strength, and Engine overrides behind **Show advanced program controls**.
- Removed the duplicate Mission-edit action from the lower Journey-management card.
- Grouped guides, exercise intelligence, backups, Bell Core connection, and diagnostics under **Help & Data**.

## Layout and compatibility
- Added responsive desktop and mobile settings layouts with protected bottom-navigation clearance.
- Existing athlete profiles, Journey data, application-control choice, equipment, limitations, nutrition, Bell Core connection, and training history remain compatible.
- No backend or database migration is required.
