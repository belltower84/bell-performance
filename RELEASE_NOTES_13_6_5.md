# Bell Performance 13.6.5 — Recovery Day Flow

## Direct recovery launch
- Recovery-only days now use **Start Recovery** as the primary dashboard action.
- The primary action opens the recovery routine directly instead of opening the Recovery information drawer first.
- Completed recovery days display **Recovery Complete** while still allowing the athlete to reopen the session.

## Recovery actions
- **View Session** is replaced with **View Recovery** when no strength or Engine session is scheduled.
- View Recovery opens the same prescribed recovery session and no longer becomes disabled or redirects to the weekly plan.
- **Modify** becomes **Recovery Options**, preserving access to readiness details, check-in controls, and recovery-session settings.

## Recovery player
- Recovery-only days identify the mobility player as a **Recovery Session**.
- The completion action uses **Finish Recovery Session** and the completed state uses **Recovery Completed**.
- Training-day mobility continues to use the existing Daily Mobility language.

## Compatibility
- Existing mobility settings, completed dates, readiness history, training plans, active workouts, equipment locations, and Bell Core data remain compatible.
- No backend or database migration is required.
