# Bell Performance 13.6.6 — Training Library Pilot

## Summary
Introduces the first premium Training Library pilot inside Bell Performance.

## What changed
- Replaced the old generic Exercise Intelligence Library screen with a redesigned Training Library home.
- Added a pilot library of 10 featured movement guides:
  - Back Squat
  - Deadlift
  - Bench Press
  - Overhead Press
  - Pull-up
  - Dumbbell Row
  - Split Squat
  - Hip Thrust
  - Plank
  - Kettlebell Swing
- Added category chips, search, pattern browsing, and favorites.
- Built a premium exercise detail experience with:
  - instructional artwork area
  - setup
  - execution
  - Bell coaching cues
  - common mistakes
  - muscles worked
  - equipment
  - substitutions / similar lifts
- Completed the first full premium guide structure for Back Squat and applied the same layout to the other pilot exercises.
- Connected the new guide experience to the exercise replacement workflow with “Open guide” links from the swap modal.
- Updated service worker cache naming and asset version strings for the new library build.

## Intent
This release is the pilot version used to validate Training Library navigation, readability, layout, and guide structure before scaling the full library.
