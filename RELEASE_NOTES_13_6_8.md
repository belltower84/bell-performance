# Bell Performance 13.6.8 — Compact Exercise Guide Header

## Summary
Streamlines the top of the full-width Training Library exercise guide so the instructional workout content begins much higher on the page.

## Changes
- Removed the large category-chip stack from individual exercise guide pages.
- Rebuilt the exercise header as a compact, non-sticky toolbar.
- Reduced the exercise title size while preserving clear hierarchy.
- Kept Back to Library, search, favorites, similar lifts, and exercise tags.
- Added responsive layouts that use one compact row on wide screens and a controlled two-row or stacked layout on smaller screens.
- Ensured the guide header remains in normal page flow and cannot cover the instructional artwork card.
