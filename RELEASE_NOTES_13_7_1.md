# Bell Performance 13.7.1 — Production Back Squat Guide

## Summary
Back Squat is now the first production-quality Exercise Guide in Bell Performance and establishes the visual standard for the rest of the Training Library.

## Changes
- Replaced the prototype Back Squat artwork with the approved production black-and-gold instructional plate.
- Added the approved production Back Squat anatomy plate.
- Displays quads and glutes as primary muscles and adductors and core as secondary muscles.
- Preserved the shared 13.7.0 Exercise Guide schema for future library expansion.
- Kept setup, execution, Bell coaching cues, corrections, equipment, substitutions, similar lifts, favorites, and workout replacement integration.
- Refined responsive sizing so the full production assets remain readable without cropping on desktop or mobile.
- Updated service-worker cache and asset versions.

## Testing focus
This release is intended for owner use and initial friend testing of the flagship guide experience before production artwork is created for the remaining exercise library.
