# Bell Performance 13.7.11 — Readiness Time Budget Repair

- The commercial Home dashboard now uses the same daily session budget as Today’s Mission.
- Required Strength + Engine minutes now equal the time selected in Daily Readiness.
- Optional Engine work is excluded from the required total and labeled clearly.
- Strength and Engine cards are selectable on the Home dashboard.
- Start and View actions now target the selected session directly.
- The workout player receives the allocated duration and trims lower-priority strength work to fit.
- Check-in detection now tolerates repaired or migrated readiness records instead of reverting to full planned duration.
