# Bell Performance 13.7.5 — Settings Flow Rebuild

This release redesigns every Settings follow-on screen to match the clean Control Center entry page.

## Changes
- Replaced dense stacked settings pages with consistent expandable section rows.
- Added a route summary at the top of Athlete Profile, Mission & Program, Training Setup, Recovery & Nutrition, Bell Behavior, and Help & Data.
- Kept one section open at a time to reduce visual overload on phones.
- Preserved all existing inputs, save actions, mission controls, equipment editing, backups, and diagnostics.
- Improved mobile spacing, field sizing, action hierarchy, and scroll behavior.
- Corrected the Athlete Profile field label from Programming Profile to Sex.
