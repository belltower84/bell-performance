# Bell Performance 13.7.9 — Dual Session Launch

- Uses concise athlete-facing names inside the workout player and preview screens.
- Keeps the full coaching-engine descriptor as internal programming metadata.
- Adds separate **Start Strength** and **Start Engine** actions when both sessions are prescribed on the same day.
- Each action launches the exact matching planned session.
- Completed strength and engine sessions receive independent completion states.
- Preserves single-session and recovery-day behavior.
