# Bell Performance 13.22.1 — Integrated Movement Preparation Scheduling

## Strength days
- Adaptive Movement Preparation now lives inside the strength workout.
- The preparation screen uses the same detailed movement cards, dosage, coaching cue, rationale, and completion controls as the standalone experience.
- Preparation is required before working sets begin.
- Completing the integrated preparation records the day’s mobility/prehab work automatically.
- The workout preview identifies Movement Preparation as an integrated portion of the strength session.

## Non-strength days
- Healthy athletes receive Optional Movement Prehab as a separate daily support session.
- Athletes with an active injury profile receive Required Rehab Support or Injury Support.
- Rehab Support counts as required daily work until the injury profile is cleared or deactivated.
- A red-flag safety screen pauses exercise support rather than generating a session.

## Scheduling transparency
- Strength-day dashboard cards direct the athlete into the strength session instead of opening a duplicate mobility modal.
- Daily mission rows no longer list mobility as a separate session when it is already integrated into strength.
- Strength-session descriptions explicitly state that required movement preparation is included before working sets.
