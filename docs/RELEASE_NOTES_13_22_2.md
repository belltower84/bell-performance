# Bell Performance 13.22.2 — Integrated Warm-Up Phase Sequence

## Strength-session sequence
1. **General Warm-Up** — five minutes of easy bike, rower, treadmill, jog, walk, or available continuous movement.
2. **Move** — adaptive joint and range-of-motion work selected for today’s session.
3. **Activate** — low-fatigue activation and pattern rehearsal.
4. **Ramp** — actual lift-specific ramp sets for the first primary exercise when a working load is available.

## Behavior
- All phases live inside the strength workout and must be completed before working sets.
- The general modality adapts to saved equipment and gives symptom-aware guidance when an injury profile is active.
- Non-strength-day optional prehab and required injury Rehab Support behavior remains unchanged.
- The workout preview now identifies the integrated sequence as Raise / Move / Activate / Ramp.
